# 🍕 What is PizzaTime?

It's is a lightweight, fun app that helps teams bond, appreciate each other, and celebrate wins simply by sending each other virtual pizza slices 🍕
 
Say **"thanks"** with a slice of pizza, unlock new recipes, collect achievements, and bring a little joy to your workplace.

_PS: It’s a passion project I built outside of my regular 9-5 work hours as a side project. I made it public so more teams could enjoy it, as everyone loves pizza!_
